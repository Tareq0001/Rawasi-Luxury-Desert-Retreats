## 🌌 نظرة عامة | Overview

**رَواسي (Rawasi)** هي منصة ضيافة فائقة الفخامة (Awwwards & Kinfolk/Aman Resorts Level) للتخييم البيئي الصحراوي ومحميات السماء المظلمة (Dark-Sky Preserves) في أبرز 4 وجهات جغرافية وطبيعية في المملكة العربية السعودية:
1. **وادي عِشار - العلا (AlUla Ashar Valley)**: قباب زجاجية جيوديسية بانورامية 360 درجة بين أخاديد الحجر الرملي النحتية.
2. **مرتفعات السودة - عسير (Asir Cloud Peaks)**: أكواخ العرعر المعلقة على حافة الأجراف الأسطورية فوق بحر الغيوم على ارتفاع 3,015 متر.
3. **صحراء حِسمى والديسة - تبوك (Tabuk Hisma Red Sands)**: مضارب السدو الملكية بين الأقواس الصخرية الحمراء وسماء كوزمولوجية نقية تماماً لرصد الشهب.
4. **كثبان الشاطئ العذراء - البحر الأحمر (The Red Sea Coastal Dunes)**: فلل بيئية مستدامة صفر-كربون تطفو برفق فوق الكثبان الساحلية والخلجان الفيروزية.

## ✨ المميزات التفاعلية الرئيسية | Key Capabilities

### 1. 🔭 مرصد النجوم وسماء الليل التفاعلي (Interactive Celestial Observatory)
- محاكاة كانفاس (Canvas 2D) فائقة السلاسة لـ 450+ نجم حقيقي متلألئ، وسحب سديمية غازية، وزخات شهب حية.
- رصد تفاعلي لأشهر الكوكبات وعناقيد النجوم المرئية في سماء الجزيرة العربية:
  - **كوكبة الجَبّار (الجوزاء عند العرب)** مع نجوم إبط الجوزاء وريجل وحزام الجبار وسديم M42.
  - **الدب الأكبر (بنات نعش الكبرى)** ومؤشرات النجم القطبي (الجدي).
  - **ذات الكرسي (الكف الخضيب)** في مجرة درب التبانة.
  - **عنقود الثريا (الشقيقات السبع)** ومنازل القمر التراثية.
- محاكي مقياس بورتل للتلوث الضوئي (Bortle Dark-Sky Scale) من الفئة 1 (العلا وحسمى) إلى الفئة 4.
- ودجت مباشر لحساب أطوار القمر الحقيقية مع مؤشر جودة التصوير الفلكي (Astrophotography Index).
- رادار الكواكب المرئية الليلة (المشتري، زحل، الزهرة).

### 2. ⛺ أطلس الملاذات والمنتجعات الصحراوية (Retreats Atlas)
- تصفية متقدمة حسب التضاريس الجغرافية (Canyon, Mountain, Crimson, Coastal).
- زر تبديل المشهد الفوري بين **ضوء النهار الذهبي** و**سماء الليل المرصعة بالنجوم**.
- بطاقات مواصفات شاملة: الارتفاع فوق سطح البحر، الإحداثيات الوعرة GPS، درجة الحرارة، وتصنيف السماء.

### 3. 🛠️ استوديو تخصيص الخيمة والكبينة الذكية (Smart Dome Configurator Studio)
- اختيار النمط المعماري للمسكن:
  - **قبة جيوديسية زجاجية بانورامية 360° (Geodesic Glass Dome)**.
  - **سرادق السدو الملكي الفاخر (Royal Sadu Pavilion)**.
  - **جناح إيرستريم الفضي الكلاسيكي (Luxury Silver Airstream Suite)**.
- تخصيص التجهيزات والخدمات الفاخرة:
  - تلسكوب سيلسترون 8 بوصة محوسب.
  - جلسة سمر مع حطب الأرطى والغضا.
  - جاكوزي دافئ خاص تحت النجوم.
  - مرشد فلكي وباحث تراثي خاص.
  - مائدة عشاء سعودية أصيلة وقهوة خولانية.
- محاكي رسومي ثلاثي الأبعاد للمسكن ومحرك تسعير فوري مع حساب ضريبة القيمة المضافة (15% VAT).

### 4. ❄️ حاسبة الطقس وبرودة ليل الصحراء (Weather & Desert Night Chill Advisor)
- حساب الفارق الحراري الحاد بين النهار والليل (Diurnal Temperature Drop) في الصحراء.
- حساب درجة الحرارة المحسوسة مع هبوب الرياح (Wind Chill Factor).
- حقيبة التجهيزات الذكية التفاعلية (قائمة التحقق من الملابس ومعدات الرصد).

### 5. 🎫 تذكرة الإقامة الفاخرة وتصريح الرصد الفلكي (Luxury Desert Boarding Pass)
- تصميم فخم يحاكي تذاكر الرحلات الفاخرة مع حواف ذهبية ورمز QR ديناميكي ورقم حجز مرجعي (PNR: `RAWASI-ULA-XXXX`).
- تنسيق طباعة فائق النقاء (`window.print()`) يحجب واجهة الموقع ويطبع التذكرة فقط كـ PDF أو مستند ورقي أنيق.

### 6. 🔥 أصوات السمر والصحراء (Web Audio API Procedural Synthesizer)
- توليد صوتي إجرائي بالكامل لأصوات طقطقة حطب السمر ونسمات الرياح الصحراوية الهادئة دون أي ملفات صوتية خارجية.

### 7. 🌐 ثنائي اللغة والسمة (Bilingual i18n & Dual Theme)
- دعم كامل للعربية الأصيلة والإنجليزية مع تبديل لحظي للاتجاه (RTL / LTR).
- مظهرين فاخرين: سماء الليل المرصعة بالنجوم (Dark Celestial) وكثبان الرمال المشمسة (Sunlit Golden Dunes).

## 🛠️ التقنيات المستخدمة | Tech Stack
- **Framework**: Vite + TypeScript (Clean Modular ES2022).
- **Styling**: Pure Modern CSS (Liquid Glass, Aurora UI, CSS Custom Properties).
- **Audio**: Web Audio API (Procedural Noise, BiquadFilters, LFOs, Exponential Decays).
- **Canvas**: HTML5 2D Canvas with Parallax Engine & Particle Physics.
- **Typography**: Google Fonts (Cinzel, Playfair Display, Tajawal, Cairo, Inter).
